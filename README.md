# gptsrl.com

Jekyll site for gptsrl.com, deployed via Cloudflare Pages.

## Running locally

### First time

From the project root, run:

```bash
docker run --rm \
  --platform linux/amd64 \
  -v "$PWD:/srv/jekyll" \
  -p 4000:4000 \
  jekyll/jekyll:latest \
  sh -c "bundle install && bundle exec jekyll serve --force_polling --host 0.0.0.0"
```

Open [http://localhost:4000](http://localhost:4000).

> Code changes are picked up automatically — just save and refresh the browser.

### Reusing an existing container

**From the terminal:**

```bash
docker start -a <container-name>
```

To find the container name:

```bash
docker ps -a
```

**From Docker Desktop:**

Open Docker Desktop, go to the **Containers** tab, find the container, and click the play button to start it. Then open [http://localhost:4000](http://localhost:4000).

## Branches

| Branch | Purpose |
|--------|---------|
| `main` | Production — deploys to https://www.gptsrl.com/ |
| `working` | Testing — preview before merging |

Do your work on `working`, then merge into `main` when ready to go live:

```bash
git checkout main
git merge working
git push origin main
```

## Deploy

Cloudflare Pages deploys automatically on every push:

- `main` → production (https://www.gptsrl.com/)
- `working` (and any other branch) → preview URL (generated by Cloudflare)
