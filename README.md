# gptsrl.com

Jekyll site for gptsrl.com, deployed via Cloudflare Pages.

## Running locally

### Option A — Persistent container (recommended)

Creates a named container that **stays around after stopping**, so you can restart it without reinstalling dependencies.

**First run:**

```bash
docker run --name gptsrl-jekyll \
  --platform linux/amd64 \
  -v "$PWD:/srv/jekyll" \
  -p 4000:4000 \
  jekyll/jekyll:latest \
  sh -c "bundle install && bundle exec jekyll serve --force_polling --host 0.0.0.0"
```

**Subsequent runs:**

```bash
docker start -a gptsrl-jekyll
```

Or from Docker Desktop: open the **Containers** tab, find `gptsrl-jekyll`, and click the play button.

### Option B — Throwaway container

Adds `--rm`, which **automatically deletes the container on stop**. Useful for a clean one-off run; runs `bundle install` every time.

```bash
docker run --rm \
  --platform linux/amd64 \
  -v "$PWD:/srv/jekyll" \
  -p 4000:4000 \
  jekyll/jekyll:latest \
  sh -c "bundle install && bundle exec jekyll serve --force_polling --host 0.0.0.0"
```

---

Open [http://localhost:4000](http://localhost:4000).

> Code changes are picked up automatically — just save and refresh the browser.

To list all containers (including stopped ones):

```bash
docker ps -a
```

## Branches

| Branch | Purpose |
|--------|---------|
| `main` | Production — deploys to https://www.gptsrl.com/ |
| `working` | Testing — preview before merging |

Do your work on `working`, then merge into `main` when ready to go live:

```bash
git checkout main
git merge working
git push origin main
```

## Deploy

Cloudflare Pages deploys automatically on every push:

- `main` → production (https://www.gptsrl.com/)
- `working` (and any other branch) → preview URL (generated by Cloudflare)

## Domain setup

The canonical domain is `www.gptsrl.com`. The bare domain `gptsrl.com` redirects to it.

To configure the redirect in Cloudflare:

1. Go to your domain in the Cloudflare dashboard
2. Open **Rules** → **Redirect Rules**
3. Create a new rule:
   - **If:** hostname equals `gptsrl.com`
   - **Then:** redirect to `https://www.gptsrl.com/` (301 — Permanent)
